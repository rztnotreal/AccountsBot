# 🤖 Claude Accounts Bot

Telegram-бот учёта аккаунтов Claude для команды селлеров. Node.js + PostgreSQL, всё управление — кнопками прямо в чате команды.

## Возможности

- **Хранит:** почту, пароль, тип подписки, дату добавления, кем забронирован, кем выдан, кем возвращён, статус.
- **Статусы:** 🟢 свободный → 🟡 забронированный → 🔵 выдан → 🟣 возвращённый, плюс 🔴 заблокированный (админ).
- **Бронирование:** аккаунт можно забронировать или взять сразу **только** если он свободный/забронированный (свою бронь). Привязка к селлеру — по Telegram ID, в списках отображается его `@username`.
- **Меню кнопками:** список с фильтрами и постраничной навигацией, карточка аккаунта с действиями по статусу, поиск по почте, добавление аккаунта пошаговым сценарием, статистика, журнал действий (кто и что сделал), управление командой (роль селлер/админ), показ/скрытие пароля.
- **Безопасность:** пароль по умолчанию скрыт, удаление — с подтверждением, атомарные переходы статусов в PostgreSQL (два человека не смогут взять один аккаунт одновременно), все действия пишутся в журнал.

## Схема статусов

```
🟢 Свободный ──🎫 Забронировать──▶ 🟡 Забронирован ──💳 Выдать себе──▶ 🔵 Выдан
      │                                    │                              │
      │◀──────────❌ Снять бронь───────────┘                              │
      │                                                                   ▼
      │◀──────────♻️ Сделать свободным────── 🟣 Возвращён ◀──↩️ Вернуть──┘

🟢/🟡/🔵/🟣 ──(админ)⛔️ Заблокировать──▶ 🔴 Заблокирован ──(админ)♻️ Разблокировать──▶ 🟢
```

- `🎫 Забронировать` / `⚡ Взять сразу` — только со статусом 🟢.
- `💳 Выдать себе` — только из своей брони.
- `↩️ Вернуть` — может только тот, кому выдан (или админ).
- `♻️ Сделать свободным` — из возвращённого (кто вернул или админ).

## Установка

1. **Node.js 18+** и **PostgreSQL** (создайте базу, например `claude_accounts`).

2. Зависимости:

   ```bash
   npm install
   ```

3. Конфигурация:

   ```bash
   copy .env.example .env
   ```

   Заполните `.env`:

   | Переменная | Описание |
   |---|---|
   | `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
   | `ADMIN_IDS` | Telegram ID администраторов через запятую (узнать: команда `/id` в боте) |
   | `ALLOWED_CHAT_IDS` | id чатов, где работает бот (через запятую). Пусто = везде |
   | `DATABASE_URL` | строка подключения PostgreSQL (или `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME`) |
   | `TZ` | часовой пояс дат, по умолчанию `Europe/Moscow` |

   > ID группы узнать можно так: добавьте бота в чат и напишите `/id` — бот ответит вашим ID. Для групп лучше уточнить ID чата у админа сервера (или через @getidsbot).

4. **Важно — отключите Privacy Mode:** [@BotFather](https://t.me/BotFather) → `/setprivacy` → выберите бота → **Disable**. Без этого бот не увидит текстовые сообщения в группе и пошаговое добавление аккаунтов не заработает.

5. Запуск:

   ```bash
   npm start
   ```

   Схема БД создаётся автоматически при первом старте (для справки: `db/schema.sql`).

## Команды

| Команда | Описание |
|---|---|
| `/menu`, `/start` | главное меню с кнопками |
| `/add` | добавить аккаунт (пошагово: почта → пароль → подписка) |
| `/find` | поиск аккаунта по части почты |
| `/stats` | статистика по статусам и подпискам |
| `/cancel` | отменить текущий ввод |
| `/help` | как пользоваться |
| `/id` | ваш Telegram ID |

## Роли

- **🛒 Селлер** (по умолчанию все, кто нажимает кнопки): брать/бронировать/выдавать/возвращать свои аккаунты, добавлять аккаунты, искать, смотреть список и статистику.
- **👑 Админ** (из `ADMIN_IDS` или повышен через «👥 Пользователи»): всё то же самое + блокировка, удаление, снятие чужих броней, управление ролями.

## Структура проекта

```
├── db/schema.sql          # схема БД (для справки)
├── src/
│   ├── index.js           # точка входа: middleware, команды, запуск
│   ├── config.js          # чтение .env
│   ├── db.js              # PostgreSQL: схема, запросы, переходы статусов
│   ├── callbacks.js       # роутер всех нажатий кнопок
│   ├── flows.js           # пошаговые сценарии: добавление, поиск
│   ├── keyboards.js       # инлайн-клавиатуры
│   ├── texts.js           # тексты сообщений
│   ├── dialogs.js         # состояние пошаговых сценариев
│   └── utils.js           # форматирование дат, экранирование, упоминания
└── .env.example
```
